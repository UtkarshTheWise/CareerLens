# F7 — Application tracker
Five contract statuses as responsive Kanban columns. Native desktop drag/drop changes status; keyboard/touch status select calls the same function. Optimistic local status with per-card synchronous lock, API acknowledgment, rollback and exact-status retry. Cards show supplied company/title/deadline and keyword/evidence mini rings, no fabricated matches. Accessible Radix dialog validates manual company/title/http(s) URL/date and creates through generated client; retain draft on error, duplicate lock, add acknowledged item and refetch list. Separate profile/list/add/move loading/error/empty states. Files: tracker route, components/tracker/tracker-screen.tsx, lib/application-draft.ts and tests; own checkpoint/handoff. Existing radix-ui, no dependencies. Validate drag/keyboard/save/fail rollback/retry/draft/no-profile/theme/responsive/axe.
